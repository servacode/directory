# Directory Platform v1.0.0 — Release Manifest

**Launch market:** Raqqa, Syria
**Initial public scope:** Pharmacy directory + Pharmacy Duty
**Status:** PREPARED — NOT RELEASED

## Architecture

The release contains a generic province-based directory engine even though the initial public experience exposes pharmacies only. Category groups, categories, per-governorate activation and verification policies are Admin-controlled.

Preconfigured but initially disabled categories include Medical Laboratory, Medical Clinic, Nursing Center and Medical Supplies. Future generic commercial/service categories may be created from Admin without an app release when they use common capabilities.

## Release blockers still external

- final dependency lockfile and production builds;
- Android native scaffold/signing/AAB;
- live PostgreSQL/PostGIS migration/restore and staging E2E;
- production domain/server/map style;
- WhatsApp recovery provider credentials if enabled;
- store listing/privacy URL and Google Play submission.

Only after all blockers pass may this document status become `RELEASED` and Git tag `v1.0.0` be created.
